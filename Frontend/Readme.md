<h1 align="center">🇬🇧 Task List V2 (Front-End) - 🇧🇷 Lista de Tarefas V2 (Front-End)</h1>

<p align="center">
  <b>🇬🇧</b> - Welcome to the Front-End repository of Task List V2! Completely redesigned with a modern and minimal aesthetic built on React, TypeScript, and Tailwind CSS. Unlike V1, which stored tasks only in localstorage, V2 integrates with a full-stack REST API and MongoDB database, featuring secure authentication, real-time Toastify notifications, and an intuitive user interface.
  <br/><br/>
  <b>🇧🇷</b> - Bem-vindo ao repositório Front-End do Lista de Tarefas V2! Totalmente reformulado com uma estética moderna e minimalista utilizando React, TypeScript e Tailwind CSS. Diferente da V1, que armazenava os dados apenas no localstorage, a V2 conecta-se a uma API REST com banco de dados MongoDB, contando com autenticação de usuários, notificações em tempo real com React Toastify e uma interface intuitiva.
</p>

<h2 align="center">🇬🇧 How to Run - 🇧🇷 Como Executar</h2>

```bash
# Clone the repository / Clone o repositório
git clone [https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git](https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git)

# Enter the directory / Entre no diretório
cd frontend

# Install dependencies / Instale as dependências
npm install

# Run the project / Inicie o projeto
npm run dev
```
